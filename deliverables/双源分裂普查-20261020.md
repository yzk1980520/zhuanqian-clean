### 1.1 判定方法

1. 求交集：`os.listdir('.')` 的 `.py` ∩ `os.listdir('scripts')` 的 `.py` → 102。
2. 对每个文件做**归一化后**比较（不是裸 md5）：

## 2. B 段 · 谁在用（导入方 + 解析目标 + 调度引用）

### 2.1 解析规则（已实测，不是推断）

Python 运行 `python scripts/foo.py` 时 `sys.path[0]` = `scripts/` 目录（绝对）。因此：

| 场景 | 最终 `sys.path` 前两位 | `import X` 解析到 |
|---|---|---|
| 根脚本直接跑（`python foo.py`，cwd=根） | `[根, ...]` | **根侧** |
| `scripts/` 脚本**有** P2-1b 序言 / 显式 `insert(0, 根)` | `[根, scripts, ...]` | **根侧**（序言里 root 是后插的，反而排在最前） |
| `scripts/` 脚本**只** `insert(0, scripts)` 或无任何 path 操作 | `[scripts, ...]` | **`scripts/` 侧** |
| `scripts/` 脚本先插 root 再插 `root/scripts` | `[scripts, 根, ...]` | **`scripts/` 侧** ← 反直觉陷阱 |

实测命令与输出：


## 3. C 段 · 风险分级

### 3.1 分级判据

- **S 级**：两侧行为不一致 **且** 已确认有真实调度/生产调用方打向 `scripts/` 侧 **且** 失败方向是资金动作（锁死不出票 或 该拦没拦）。
- **A 级**：两侧行为不一致，但目前主要调用方打向根侧；一旦有任何路径切到 `scripts/` 侧即退化成 S 级。或：两侧不一致且影响**数据落盘位置**。
- **B 级**：内容等价，但双份导致模块身份/状态分裂，或 `scripts/` 侧路径常量算错（会读写 `scripts/data/`）。
