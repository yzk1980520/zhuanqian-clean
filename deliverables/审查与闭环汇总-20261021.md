## 三、本轮最值钱的两个发现（防的是下一遍）

### ① `check_all` 直跑 pytest 文件 = 永远假绿
`_run_script` 对 AUTO_RUN 项执行 `[sys.executable, script_path]`，而 **pytest 用例文件直跑不执行任何用例、直接 exit 0**（实测 `python tests/test_no_remote_egress.py` → exit 0 零输出）。若把测试当普通脚本挂进必跑列表，会造出一个"看起来接了"的死映射——比不接更糟。正解：`_run_script` 加通用分支识别 `tests/test_*.py` 走 `-m pytest`。

### ② 门禁分数上升要先排除 erosion
18/3/1 → 20/1/1 曾被疑"门禁放松"。实证排除：接线 commit 是 **41 insertions / 0 deletions**（纯增量）+ G6/G7 是源码层修复转绿 + walk-forward 数值与 10-20 完全一致。
