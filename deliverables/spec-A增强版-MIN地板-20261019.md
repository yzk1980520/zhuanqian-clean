## 背景

R9（回测必须含退市股）的核心价值是「132只真实退市样本参与回测」。
当前守卫 `test_delisted_coverage.py` 只卡 `with_data_count > 0`，挡不住渐进侵蚀：
- 157→10 照样PASS（只要exclusive_count>0）
- 未来若有人把退市股从池子里剔光（违反D8拍板），守卫不会FAIL

## 方案：A增强版

**保留现`>0` + 加下限定板 `>= MIN_DELISTED_IN_BACKTEST`**

### 代码改动

**文件**：`tests/test_delisted_coverage.py`

```python
# 新增常量（L1附近）
MIN_DELISTED_IN_BACKTEST = 91  # R9幸存者偏差地板: 2026-10-17实测with_data_count
                                # 变更须走 CONTRACT-CHANGELOG + 广播

# 新增测试用例（L220后）
def test_gate_fail_when_with_data_below_threshold(audit_path, tmp_path):
    """【红】with_data_count < R9地板 → FAIL（渐进侵蚀）"""
    audit = {
        "exclusive_count": 157,
        "with_data_count": 90,  # < MIN_DELISTED_IN_BACKTEST (91)
        "st_skipped": 66,
        "empty_count": 0,

        "generated": "2026-10-19T01:50:00",
        "st_filter_source": "backtest.is_st_stock"
    }
    _write(audit_path, audit)
    ok, detail = check_delisted_coverage(audit_path)
    assert not ok, f"应FAIL但PASS: {detail}"
    assert "below R9 floor" in detail or "MIN_DELISTED" in detail

def test_gate_pass_when_with_data_at_threshold(audit_path, tmp_path):
    """【绿】with_data_count == R9地板 → PASS"""
    audit = {
        "exclusive_count": 157,
        "with_data_count": 91,  # == MIN_DELISTED_IN_BACKTEST
        "st_skipped": 66,
        "empty_count": 0,
        "thin_count": 0,
        "generated": "2026-10-19T01:50:00",
        "st_filter_source": "backtest.is_st_stock"
    }
    _write(audit_path, audit)
    ok, detail = check_delisted_coverage(audit_path)
    assert ok, f"应PASS但FAIL: {detail}"
```

4. **全量回归**：`pytest tests/test_delisted_coverage.py -v` 17→19测试全绿
