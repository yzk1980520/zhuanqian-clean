## 三、脚本说明：`scripts/w3b_silence_real_sources_elevated.ps1`

- **纯 ASCII**（已校验：0 个 >127 字节；PS 语法解析 PARSE OK）——GBK 下不会被吃掉引号。
- **绝不自我提权**：不在管理员组就打印提示并 `exit 1`（UAC 弹到老大桌面正是静默规则禁止的）。
- **`-Apply` 开关**：不带 = 只打印计划（DRY）；带 = 才真正 `Register-ScheduledTask`。
- **每个任务改动前打印 `old=`** 便于对账。
- **逐个 try/catch**，单个失败不影响其他。
- 两个区块：Block A（13 个真弹源，换命令 + Hidden）、Block B（3 个只补 Hidden）。
- 关于"不要为了静默丢掉日志"：
  - `.bat`/`.cmd` 类（`daily_auto.bat` / `Zhuanqian_FactorIC132d.bat` / `Zhuanqian_WalkForward.bat`）
    本身内部就有 `>> ... 2>&1`，走 vbs 启动器后**日志照写，一条不掉**。
  - 直接 `python.exe` 的几个脚本当前**没有任何日志文件**（输出直接丢进一闪而过的 conhost），
    换 `pythonw.exe` 不会丢掉任何"本来就存在的日志"；同时这也是本项目既有做法
    （`Zhuanqian_RefreshTaskBoard` 用的就是 `pythonw.exe`）。
  - 已确认两个 venv 的 `pythonw.exe` 与 `Python311\pythonw.exe` 都在盘上。

## 四、老大需要做什么（一条命令）

**先**用管理员身份打开 PowerShell（开始菜单 → PowerShell → 右键"以管理员身份运行"；这一步会弹一次 UAC，之后脚本本身不再弹），**然后**复制这一条：

```
powershell -ExecutionPolicy Bypass -File "D:\open code\zhuanqian\scripts\w3b_silence_real_sources_elevated.ps1" -Apply
```

想先看计划再决定，用这条（同样需要管理员身份，否则脚本会拒绝并 exit 1）：

```
powershell -ExecutionPolicy Bypass -File "D:\open code\zhuanqian\scripts\w3b_silence_real_sources_elevated.ps1"
```

改完自检：

```
powershell -ExecutionPolicy Bypass -File "D:\open code\zhuanqian\scripts\check_silent_scheduled_tasks.ps1"
```
