## 一句话结论

**这个系统不是"没做"，是"做了但没人读"。** 三类同构断裂：

1. **守卫写了，但站的门口里没有它** —— 契约真源守卫既不在任何门禁执行面，也从没进过版本库
2. **告警发了，但发到了没人消费的地方** —— 唯一出口铁律立了，实际有 4+ 条直发绕过路径
3. **配置配了，但没有任何代码读它** —— `config.json` 26 个顶层键里 9 个整块零引用

三条都是同一个病：**写侧动作没有读侧消费断言**（AGENTS.md §4.1-12 早已立规，但注册侧整体缺失）。

## 二、本次已修（3 处 P0，均已实测验证）

### 2.1 pytest 门禁自递归 fork 弹（commit `b518dccc`）

- **根因**：`test_git_sync_gate_logic.py::TestGateFunctionDirectly` 直接调生产函数
  `run_pytest_gate()`，而后者 glob `scripts/test_*.py` 派生 pytest → 无限自递归
- **实测**：递归 34 层 / 单轮 539s / 49 个 `python.exe` / 每 3.4s 净增 1 个
- **修**：① 僵尸测试隔离出 `scripts/`（它断言的 `frozen_since` / `force-with-reason` /
  `pre_existing` 三个 API **全仓只存在于它自己**，是幽灵接口）
  ② `ZQ_PYTEST_GATE` 环境变量哨兵（唯一能防同类复发）
  ③ 超时改 `Popen` + `taskkill /T /F` 杀整树（Windows 原只 kill 直接子进程）
  ④ `self_heal_check` P-04 拆独立 repair + ≥6h 冷却（原无冷却，单日触发 47 次）
- **验证**：539s → **5.17s**，5 failed 全消；对照实验确认哨兵**靠继承即生效**

## 三、实证推翻的一条误报（重要，防止误导决策）

取证 worker 报：**「P0：`backtest_rotation.py:1181` 按最终名称整只剔除含退的票 = 逆转 R9 幸存者偏差修复」**

**实测推翻 —— R9 完好：**

```
BT.is_st_stock is BT.is_st_only          = True      ← backtest.py 有兼容别名
BT.is_st_stock is tdx_data.is_st_stock   = False
  某某退      BT(回测)=False  tdx_data(实盘)=True     ← 退市股回测侧保留
  退市锐电     BT(回测)=False  tdx_data(实盘)=True
回测口径剔除(ST/*ST, 不含退) = 216
实盘口径剔除(含退)          = 303
=> R9 救下的退市股 = 87
```

`backtest.py` 里 `is_st_stock = is_st_only` 是刻意设计的兼容别名，注释写明
「避免 7 个调用点 AttributeError」。**87 只退市股被正确保留在回测池。**

> 教训（与 MEMORY 记载同源）：**凡引用报告/文档里的行号或符号名指针，必须先验证它真的是那个东西。**

## 五、架构判断

**主反模式 = 大泥球（Big Ball of Mud）+ 配置漂移（Configuration Drift）**，
叠加**写侧无读侧断言**（本仓特有病，已 5 次复发）。

**换一个人来维护，最容易踩的 3 个坑：**

1. **改 `config.json` 以为生效** —— `trailing.ladder`、`time_stop.max_hold_days`、
   `trade_params.chase_ban_pct`、`backtest_params.initial_capital` 看着像开关，实际零引用。
   改错文件后实盘/回测行为纹丝不动，**且不报错**。
2. **`import integrated_picker` 永远拿到包、拿不到根模块**（包目录优先）。
   在 `layers/l1_tradability.py`「统一」改阈值，改的是影子副本（其 ATR 已是裸值 bug），
   生产跑的根模块那份没动，且守卫**覆盖不到 layers/**。
3. **回测赚钱 ≠ 实盘赚钱** —— 最少K线 120 vs 30、ATR%、接飞刀三项不对称，
   回测选出的票有相当部分在实盘前端过滤里直接被毙掉。
