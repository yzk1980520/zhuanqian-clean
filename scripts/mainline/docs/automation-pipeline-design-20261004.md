【降级方案】

情况1: P0-2未审批
  → 跳过选股，仅运行IC监控
  → 生成异常报告，标注P0-2未解决

情况2: P0-1因子失效
  → 禁止选股操作
  → 维持空仓观望
  → 每日检查ICIR，待ICIR>0.5再恢复

情况3: 数据滞后>10天
  → 使用本地缓存数据
  → 标注数据新鲜度⚠️
  → 优先补充akshare数据

【执行保障机制】

1. 双保险Cron
   - 系统级cron（已配置）
   - Hermes cron（已配置）
   - 双重触发，确保不遗漏

2. 异常告警
   - 门禁FAIL → 立即通知
   - 候选池<50只 → 警告
   - ICIR<0.3 → 暂停选股

3. 回滚机制
   - 每次修改保留备份
   - Git提交记录变更
   - 可一键回滚至上一版本
