## 发现的问题

### [P1] .md5 文件格式非标准，机器可校验性缺失

- **现象**：总管 10-16 执行时生成的 `.md5` 文件内容为裸 hash `fd7c457cd8d7e4235507495c4163ce43`（33 bytes，单行），缺少 ` md5sum` 标准格式所需的 ` <filename>` 后缀。
- **影响**：`md5sum -c` 报 `no properly formatted MD5 checksum lines found`，**机器无法自动核验完整性**，与 D2 流程 L41 "两侧断言一致" 的验证意图相悖。
- **根因**：D2 流程 L40 给出了正确命令 `md5sum ... > .md5`，但执行人可能手动 echo hash 而非运行命令。
- **修复**：已用 `md5sum > .md5` 标准命令重写，格式为 `fd7c457cd8d7e4235507495c4163ce43 *docs/.trash/代码审查标准与流程-v1.0-20261016.md.bak_20261016_pre_v11`，`md5sum -c` OK。
- **建议**：D2 流程文档步骤 3 增加一行验证命令示例：
  ```bash
  # 验证：md5sum -c 必须 OK
  md5sum -c .trash/<路径>/<文件名>.md5
  ```
