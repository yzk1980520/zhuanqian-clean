# QuantSkills技能集成——Phase 1经验教训（2026-09-20）

## 一、核心经验

### 1.1 因子接入策略
- **不要全量接入500+因子**，先接20-50个代表性因子验证闭环
- 先打通"数据契约 → 因子注册 → B10评估 → 样本外回测"流程
- 再逐步扩展到全量因子库

### 1.2 视角对齐
- **B10是截面多因子排序视角**，本项目是**单票轮动视角**
- 两者不可直接迁移IC结果
- 必须在本项目回测框架下重新验证

### 1.3 IC方向记录
- 必须记录IC正负方向，不可仅用绝对值
- 负IC因子反转后可能有效（如chg5从动量变为反转）
- IR筛选应使用绝对值：`abs(ir) >= min_ir`

## 五、Go/No-Go条件

1. 数据无未来函数，PIT验证通过
2. B10能复现至少3个已知因子的历史评估结果
3. 20-50个因子完成滚动样本外测试
4. 回测含成本、涨跌停、停牌、退市股
5. 输出可复现报告：代码版本、数据版本、参数、结果
6. 至少1个组合级回测跑通（Sharpe>0.5, 回撤<20%）
