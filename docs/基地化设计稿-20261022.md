## 四、灰度迁移序（每步 = 1 commit + 回归门禁，可独立回滚）

**原则**：一族一迁，迁完先验该族 cron/回归再进下一族；`risk_rules.py` 路径变更放**最后**（牵连全仓 import + cron）。

| Step | 内容 | 回归门禁（不绿不进下一步） | 回滚点 |
|------|------|------|--------|
| S0 | 全仓快照：`git commit` 现状为锚点；`risk_rules.py`/`atomic_json.py` 打 `.bak_基地化前` | — | commit S0 |
| S1 | 迁 `factors/`（DL 5，隔离度最高、被引用最少） | `pytest tests/` 该族 + grep 全仓 `import dl_`/`laya` 0 断链 | S0 |
| S2 | 迁 `backtest/`（11，含 `backtest_rotation.py` 主回测） | `python backtest_rotation.py` 冒烟 + `pytest -k backtest` 全绿 + `check_backtest_sanity.py` PASS | S1 |
| S3 | 迁 `core/scoring/`（17 因子评分） | `python daily_pick.py` 干跑出一只票 + 因子 IC 门禁不翻转 | S2 |
| S4 | 迁 `core/pipeline/`（22 主线） | 全链路 dry-run：`daily_pick → positioner → 风控` 不出 P0 | S3 |
| S5 | 迁 `core/ops/`（17 监控）+ `scripts/` 一次性归 `archive/` | `self_audit.py --audit` + cron `system_health` 冒烟 | S4 |
| S6 | **改 cron 指向**：15 个 cron 的 `script:`/shim 路径全量映射到新目录 + `zq_shim.run_project_script` 白名单扩到 `core/**` | `hermes cron run <每个>` 冒烟 + QSP_MsgDrain/QSP_DrainWatch 心跳正常 | S5 |
| S7 | **迁 `core/risk/`（含 risk_rules.py 红线）**：改全仓 `import risk_rules`→`core.risk.risk_rules` + `check_redline_pointer.py` 指针同步 | `tests/test_contract_docs_consistency.py` 全绿 + `check_redline_pointer.py` PASS + `risk_rules.py` 哈希不变 | S6 |
| S8 | 根级清空验收：根级 `.py` 只留 4 个真源入口（可选 `main.py`）；跑 `.agent/regression/__init__.py .` 全绿 | 回归全绿 + 三件套（结果/产出/验收） | S7 |

**每步铁律**（AGENTS §4.1 铁律 + 宪法 VII 异常不吞）：
- 改动前 `Copy-Item x.py x.py.bak_基地化`（回滚点）
- `Remove-Item Env:PYTHONPATH` 后跑
- `python -m py_compile` 语法过
- 快慢版 20 日改善须 132 日全量确认（若触及回测）
